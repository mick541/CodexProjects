# Content Factory Dzen

## Назначение

Content Factory Dzen - система подготовки, проверки и распространения контента для Яндекс Дзена.

Система создаёт тематические серии статей, проводит их через анализ ключевых слов, генерацию, AI Cleaner, фактологическую проверку и человеческую редактуру.

## Первый рабочий результат

Серия из 5-7 статей в формате Markdown с:

- ключевыми словами;
- метаданными;
- перелинковкой;
- хештегами;
- промтами обложек 16:9;
- едиными идентификаторами;
- отчётами проверки;
- возможностью ручного утверждения.

## Основной процесс

```text
Ниша
-> подниша
-> тематический кластер
-> ключевые слова
-> заголовки
-> структура
-> генерация статьи
-> AI Cleaner текста
-> проверка фактов
-> человеческая редактура
-> AI Cleaner медиа
-> проверка изображения
-> утверждение
-> ready-for-dzen
```

## AI Cleaner текста

Модуль должен:

- устранять шаблонность и повторы;
- улучшать естественность текста;
- сохранять смысл и факты;
- не добавлять непроверенные утверждения;
- заменять длинное тире на короткий дефис;
- формировать отчёт об изменениях;
- сохранять исходную и очищенную версии.

AI Cleaner не гарантирует обход детекторов. Его задача - редактура естественности, качества и индивидуального звучания.

## AI Cleaner медиа

Модуль должен:

- проверять формат 16:9;
- проверять размер изображения;
- удалять лишние технические метаданные по настройке;
- проверять наличие случайного текста, логотипов и водяных знаков;
- создавать очищенную копию;
- связывать изображение с Content ID;
- формировать отчёт проверки.

## Идентификаторы

Серия:

```text
CFD-YYYYMMDD-NNN
```

Статья:

```text
CFD-YYYYMMDD-NNN-A01
```

Идентификатор используется в статье, изображении, метаданных, промте, отчётах и анонсах.

## Главное правило публикации

Статья не попадает в ready-for-dzen без:

- AI Cleaner текста;
- проверки фактов;
- человеческой редакции;
- проверки метаданных;
- утверждённой обложки или промта;
- проверки коротких дефисов;
- Content ID.
