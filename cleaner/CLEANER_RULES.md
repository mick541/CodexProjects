# AI Cleaner — правила

## Обязательные правила

1. Сохранять смысл исходного материала.
2. Не добавлять непроверенные факты.
3. Удалять только явные повторы и технические ошибки.
4. Не менять имена, даты и числа без подтверждения.
5. Отмечать существенные изменения в отчёте.

## Проверка перед сохранением

- текст читается естественно;
- структура не нарушена;
- важная информация сохранена;
- изменения можно объяснить редактору.

## Статус

Правила подготовлены. Реализация будет добавлена позже.
