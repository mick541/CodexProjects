# Content Factory Project Passport

## Назначение

Content Factory — локальное Streamlit-приложение для SEO-исследования, подготовки SEO-брифа, генерации статей, автоматической проверки и редакторского улучшения.

## Запуск

```powershell
python -m py_compile .\app.py
python -m streamlit run .\app.py
```

Локальный адрес:

```text
http://localhost:8501
```

## Текущие функции

- SEO-исследование.
- Формирование SEO-брифа.
- Генерация статьи.
- Проверка SEO.
- Проверка правил Дзена.
- Проверка фактов.
- Автоматическое улучшение статьи.
- Повторная проверка после улучшения.
- Экспорт статьи в Markdown.
- Экспорт SEO-данных и отчёта.
