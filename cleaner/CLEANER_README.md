# Cleaner

Этот каталог предназначен для инструментов очистки и подготовки данных проекта.

Здесь будут находиться:
- скрипты очистки;
- правила обработки данных;
- инструкции по запуску;
- служебные файлы, связанные с подготовкой данных.

## Статус

Каталог создан. Инструменты будут добавляться постепенно.
